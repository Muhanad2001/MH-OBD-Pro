# MH OBD Pro — Real Data Edition

تم تحديث المشروع لقراءة بيانات OBD الحقيقية من قطعة Wi‑Fi المتوافقة مع ELM327 عبر Bridge محلي.

## ما تمت إضافته
- تهيئة ELM327 تلقائيًا: ATZ / ATE0 / ATL0 / ATS0 / ATH0 / ATSP0.
- قراءة RPM — PID 010C.
- سرعة السيارة — PID 010D.
- حرارة سائل تبريد المحرك — PID 0105.
- Throttle — PID 0111.
- MAF — PID 0110.
- MAP — PID 010B.
- جهد النظام/البطارية — PID 0142.
- قراءة DTC عبر Mode 03.
- مسح DTC عبر Mode 04.
- تحديث تلقائي للبيانات الحية.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. داخل مجلد `bridge` نفّذ:
   npm install
3. ثم:
   node server.js
4. وصّل الكمبيوتر بشبكة Wi‑Fi الخاصة بقطعة OBD.
5. افتح `public/index.html`.
6. من "توصيل القطعة" ضع IP وPort القطعة.

الافتراضي في الواجهة:
IP: 192.168.0.10
Port: 35000

## ملاحظات مهمة
- هذا الإصدار يدعم أوامر OBD-II القياسية المذكورة أعلاه، لكن مقدار البيانات الفعلية يعتمد على السيارة والقطعة.
- أرقام الشاشة قبل الاتصال بالقطعة هي وضع تجريبي للتصميم، وليست قراءات حقيقية.
- قراءة ABS/Airbag/TCM وباقي الوحدات الخاصة بالشركة المصنعة ليست مضمونة عبر ELM327 OBD-II العام؛ تحتاج دعم بروتوكول/وحدة السيارة.
- لا تمسح الأكواد إلا بعد حفظها، لأن Mode 04 يمسح معلومات الأعطال المخزنة حسب ما تسمح به السيارة.
